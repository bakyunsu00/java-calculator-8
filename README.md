## 기능 목록


### 커스텀 구분자 유무확인

- 입력값으로 들어온 문자열에서 커스텀 구분자 확인 후 기본 구분자에 추가한다.

### 문자열 계산

- 커스텀(기본) 구분자로 문자열을 구분한 후 문자들의 합을 반환한다. 

- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료된다.
